## 安装（Chrome / Edge，约 1 分钟）

1. 把 zip **解压**到一个固定文件夹（安装后不要删除该文件夹）；
2. 地址栏输入 `chrome://extensions` 回车（Edge 为 `edge://extensions`）；
3. 打开右上角（Edge 在左侧栏）的 **「开发者模式」** 开关；
4. 点 **「加载已解压的扩展程序」**，选择刚才解压出的文件夹——完成。

> Chrome 偶尔会提示「请停用开发者模式扩展」，属正常提醒，点关闭即可，插件不受影响。

## 升级方法

下载新版本 zip → 解压覆盖原文件夹内容 → 在扩展管理页找到 OneOPCAI Clipper 点 **「重新加载」**（↻ 图标）。

## 使用

1. 点击浏览器工具栏的 OneOPCAI Clipper 图标打开侧边栏；
2. 未登录时点「平台统一登录」——会在**当前窗口**新标签页打开统一登录页（@agent.qq.com 邮箱验证码），完成后自动返回并连接；
3. 在任意网页点「收藏」，页面即存入你的工作台素材库。

接入说明：https://docs.agentschool.me/agent-onboarding.md
